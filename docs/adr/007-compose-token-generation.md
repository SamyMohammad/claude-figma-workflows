# ADR-007: Approved portable receipts generate deterministic Compose themes

Compose rendering uses only the portable receipt contract and an explicit trusted core command array. It never imports installed core internals. Both CLI modes export the current bundle and compare the complete receipt plus token/manifest identities; writing rechecks after staging. The config hash is calculated from the original declarative JSON and recorded in AppThemeIdentity and the publication manifest.

Geometry px becomes dp, typography px becomes sp, and rem requires an explicit base. Decimal arithmetic preserves source conversion intent; Kotlin Float storage is reported as a precision limitation. Out-of-range/underflow Float values and non-integral or overflowing millisecond durations fail. All font resources require mapping and project-file SHA-256 verification. Multi-family fallback stacks cannot be represented faithfully and fail explicitly.

Material roles come only from explicit mappings. Unmapped roles require explicit role authorization or the exact colorScheme:unmapped, typography:unmapped, or shapes:unmapped group marker. The generation report lists all defaults; authorization never changes them into source tokens. Theme mode selection preserves typography and shape differences. The synthetic test config maps all five shape roles to its existing radius token; this is a test fixture decision, not an invented source value.

Publication asks core check-paths for every destination, stages all bytes before replacing, and owns files only while their hashes match the prior .workflow/compose-theme.json manifest. Existing handwritten files and edited generated files fail. Replacement is not a multi-file atomic transaction: rollback restores previous bytes, and failure reports error or partial with compilationAllowed false. Caller serialization remains required against concurrent writers; source changes after the final check and filesystem changes during replacement remain residual race windows. No Kotlin compilation is claimed here; C3 compiles the generated fixture.
